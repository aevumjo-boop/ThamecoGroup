THAMECO GROUP — COMPLETE STATIC WEBSITE
Exported from the current published design (version 22), 29 October 2026.

START
1. Extract the ZIP completely.
2. Open index.html in a current desktop browser, or upload this folder's contents to any static web host.
3. Keep css/, js/, and assets/ beside index.html.
No installation, package manager, compilation, backend, Python, Node.js, database, or API key is needed. JavaScript must be enabled.

INCLUDED
Home, About Us, Our Services, Contact Us; English, Turkish and Arabic with RTL support; responsive headers and mobile menu; original photography and fonts; four-stage scrolling hero; pinned coverage text and map with seven routes; scroll-synced country highlights; doctor robot emerging from the Aevum logo and walking; all current page transitions, hover effects and navigation.

CONTENTS
index.html — page entry point.
css/ — design, local fonts, responsive breakpoints, hero and map styles.
js/reference-site.js — browser-ready application and bundled client-side libraries; no npm/build step.
js/saved-v3-hero.js — translated hero markup and isolated styles.
js/immersive-shipping.js — scroll-controlled photographic journey.
js/accurate-routes.js — geographic renderer, embedded map data and scroll progression.
js/footer-mascot.js — walking doctor animation.
assets/images/ — photography, logos and transparent doctor sprite. The reference design's embedded images have been extracted into site-visual-*.jpg/png files for easier editing.
assets/fonts/ — local font files.
assets/maps/ — editable geographic and destination source JSON plus source note. The map uses an embedded copy in accurate-routes.js to avoid local-file fetch restrictions; update that embedded copy if changing the JSON.

PORTABILITY
Navigation uses #/, #/about, #/services and #/contact. No server rewrite rules are needed. Assets use relative paths; there are no external CDN dependencies. The original design/text/translations and latest footer/map changes are preserved. The CSS adapts layouts to phones, portrait tablets, landscape screens and desktops. Reduced-motion preferences are respected.
The compiled client-side JavaScript uses React and its bundled libraries; no React installation or backend runtime is required. This is the executable static frontend, not an uncompiled JSX development project.

CONTACT AND EXTERNAL LINKS
Email and telephone links open the visitor's configured apps. The Aevum logo links to aevumjo.com. There is no contact submission service or database in this export. Social links retain their current site targets.

CHECKS
All four routes were checked at 320px, 768px and desktop browser widths: no horizontal overflow and no broken loaded images. Hero photographs, pinned mobile/tablet coverage, seven destination reveals and the footer doctor were checked in the exported copy. JavaScript syntax and local asset references were checked. The ZIP includes no Python files, server scripts, credentials, repository history, development tools or obsolete saved-design assets.
Browser animation performance varies by device. A current Chrome, Edge, Firefox or Safari is recommended. Mobile OS file viewers may restrict executable web content; static hosting provides normal browser access on those devices.
